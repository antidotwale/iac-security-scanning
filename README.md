# iac-security-scanning

Scan Terraform for misconfigurations in CI and fix what it finds.

> Personal lab project. Built in my own AWS, Azure and GitHub accounts for learning and practice. It is not work I did for any employer or client. Any secrets, keys or tokens shown in test data are fake.

## What this builds

A deliberately weak Terraform example, scanners that catch the problems, the fixed version, and a pipeline gate that blocks the weak one.
